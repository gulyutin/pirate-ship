# Корабль первого класса

Воксельная пиратская игра в стиле Minecraft для первоклассника: плаваешь по открытому морю,
высаживаешься на острова со 100 чудесами света, собираешь штампы в паспорт путешественника,
копаешь клады, спасаешь моряков из бочек, ловишь рыбу и забираешься по радужному паркуру
на вершины. Перед каждым заплывом — карта удачи, в море — случайные события: торговец,
туман с сундуками, корабль-призрак.

Сделано на [three.js](https://threejs.org) и [Vite](https://vite.dev), обычный JavaScript без фреймворков.
Всё нарисовано кубиками прямо в коде, звуки и музыка синтезируются в браузере.

**Играть:** https://gulyutin.github.io/pirate-ship/

## Управление

- **Палец / мышь** — веди по экрану, корабль или капитан поплывёт туда.
- **Стрелки / WASD** — то же с клавиатуры.
- **Пробел** — прыжок, **E / Enter** — действие, **B** — на корабль, **Esc** — пауза.

## Своя команда

Имена капитана и матросов берутся из `src/crew.json`:

```json
{
  "captain": "Капитан",
  "sailors": ["Юнга", "Боцман"],
  "balbesy": ["Капитан", "Боцман"],
  "volshebnicy": ["Юнга"]
}
```

- `balbesy` — кто может случайно стать «балбесом» и чудить;
- `volshebnicy` — кто колдует в море: радуга, волшебный пузырь, звездопад.

Чтобы вписать настоящие имена и не выкладывать их в интернет, создай рядом `src/crew.local.json`
в том же формате — игра возьмёт его вместо `crew.json`, а в git он не попадёт.

## Запуск

```bash
npm install
npm run dev
```

Игра откроется на http://localhost:5173 (и в локальной сети — можно играть с планшета).
Сборка: `npm run build`. На GitHub Pages игра выкладывается сама при пуше в `main`.
